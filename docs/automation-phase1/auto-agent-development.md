# AI 自动化一期｜Auto-Agent 接入开发

在现有 Corax 会话中接入[仪器后端的四个接口](instrument-backend-development.md#接口契约)。站点地址通过现有配置管理，工具经固定客户端访问仪器后端，复用原生澄清和审批。

| 步骤                | 接入逻辑                                                                                                                                                             |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. 获取可用模板     | 一次获取可用列表，或一次按多个模板编号查找。匹配名称和用途后保留每个模板的 `templateId` 和 `versionId`。                                                             |
| 2. 选择模板创建实验 | 将用户确认的「模板版本＋管码」逐条组成 `items`，每条生成一个 `experimentId`。按现有 Corax 审批设置一次提交整批，逐项反馈。超时时用原编号批量查进度，不自动重发创建。 |
| 3. 获取中间过程     | 一次查询当前对话中已明确的一批实验编号，按编号匹配进度和各阶段时间；“这批”指哪组不明确时先询问。                                                                     |
| 4. 解析结果         | 一次查询同批实验的结果。解释已就绪项的实测指标、单位和曲线，单独列出未就绪或查询失败的项。                                                                           |

### 开发落点

- `corax/lib/automation/`：固定仪器 API 客户端及响应映射。
- `corax/tools/automation.ts`：接入四个业务操作，创建实验复用 Corax 原生审批。
- 语音转写填入现有输入框，用户编辑后发送，与文字走同一流程。

在现有 `config.json` 中启用 `"automation": { "enabled": true, "serviceURL": "https://你的仪器地址/api/automation/v1", "timeoutMs": 10000 }`，再重启 Auto-Agent。每次最多提交或查询 100 项；结果较大时，原始数据通过聊天附件返回。

提交前按仪器地址和样品管码保存待核对记录。回执未知时，同一管跨会话或重启后仍返回原实验编号，同批其他可提交的管照常处理。收到明确创建回执、明确拒绝，或按原编号查到实验后清除对应记录；查不到实验时继续保留。

联调时用混合模板批次走通四步，覆盖部分创建失败、超时后按原编号批量回查，以及同批结果部分就绪。
