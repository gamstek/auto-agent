# AI 自动化一期｜需求文档

一期直接使用现有 Auto-Agent 对话。用户通过文字或语音选用已有模板，一次提交一批「模板版本＋样品管」的组合，再成批查询模板、进度和结果。

| 步骤                | 用户需求                                                                                                   | 验收标准                                                                       |
| ------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 1. 获取可用模板     | 一次获取可用模板列表，也可按多个模板编号一起查询。                                                         | 显示可用模板的名称、版本和用途；同名且无法唯一定位时询问用户。                 |
| 2. 选择模板创建实验 | 把一批已入库样品管与各自选定的模板版本组合后一次提交。同一批可用同一个模板，也可对不同样品管使用不同模板。 | 按管返回实验编号或失败原因；单项失败不影响其他项。只有用户明确要求创建才提交。 |
| 3. 获取中间过程     | 按一批实验编号查看预处理、二次称重和分析。                                                                 | 每个实验单独显示实际状态和时间，区分待执行、进行中、已完成和失败。             |
| 4. 解析结果         | 按一批实验编号获取实测指标和已有等温线。                                                                   | 先展示并解读已就绪的结果，单独标出未就绪或数据缺失的实验。                     |

一期复用现有聊天界面和审批设置。模板选择与结果展示在 Auto-Agent 对话内完成。
