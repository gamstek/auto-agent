# 用户 LLM Wiki

## 查询

通过宿主提供的通用 Wiki 能力，使用 knowledge 集合查看目录或搜索知识页，再按返回的完整 reference 阅读；需要核对事实时回读 sources 引用的固定原文版本。跟随 nextOffset，不把摘要当作完整页面。collections 可查看其他资料集合，reference 是独立只读证据，不属于本技能的摄入对象。

知识页是 LLM 综合内容，原文是证据。回答说明两者的区别，保留来源、版本、数值、单位和未决问题。查询不会自动生成或改写知识页。

## 摄入与维护

只有用户明确要求导入、更新或重新整理知识时才进入 ingest。复用已配置来源；目录给出多个来源时按用户指定范围选择 sourceId，不擅自处理额外资料。摄入会调用模型并持久写入，失败或取消时核对 completed，不把整个批次说成全部回滚，也不自动重放失败来源。

只接受 UTF-8 Markdown/TXT，拒绝数据库、SAM 和其他二进制。不要将仪器内置资料、工具输出或聊天历史自动晋升为用户知识来源。

摄入分为原文分析与 Markdown 页面生成/合并，保留实体/主题的来源和交叉引用。冲突并列说明，不凭共同关键词转移主体的数值、能力或结论。

结构检查不能证明语义无矛盾、科学适用或设备就绪。reindex 只重建检索缓存，不能代替模型摄入。

用户明确确认待确认记录的处理结论后，可按目录返回的 issueId 使用 resolve 保存说明。它只关闭记录并追加日志，不改写正文；不能因为模型自行认为没有问题就关闭，也不把关闭记录说成科学验收。
