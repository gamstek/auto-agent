# 内置仪器参考资料

`library.sqlite` 是随 device-automation Skill 发布的历史 SAM 只读证据，通过 Agent 通用 Wiki 的 reference 集合查询，不是用户可导入的 LLM Wiki 格式。它是领域数据资产，不是技能指导文本。

人工维护的材料与测试规则位于 `../references/materials/`。两份 MD 属于 Skill 指导，直接按资源阅读，不交给 LLM 重新提炼，不作为数据库导入来源。

历史参数不代表当前仪器状态或本次实验的默认设置。保留源哈希、软件/产品版本、字段定位、单位、presence、scope、active 和历史实验模式。
