# 设备自动化与单仪器控制

## 先按当前目标路由

从用户本次目标和已知上下文选择一条入口，先读对应资料，不把所有任务套进完整测样流程。

| 当前目标                               | 按需阅读                                                          | 第一个有用操作及完成条件                                                |
| -------------------------------------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 解释 BET/BJH/DFT、单位或方法区别       | [方法与单位](./references/methods.md)                             | 依据方法定义回答；不要求样品参数或查询仪器                              |
| 尚未决定怎么测，需要材料/方法建议      | [Wiki参考](./references/wiki.md)                                  | query 通用推荐；只有具体历史设置能补足问题时才 search/read              |
| 查询 Climber 健康、状态或指定批次      | [Climber接口](./references/climber.md)                            | 按问题调用 health 或 status；给出同批次的实际状态                       |
| 检查或对比用户指定的 SAM/SMP           | [SAM解析](./references/sam.md)                                    | inspect 或 compare 指定文件；回答关注的字段和差异                       |
| 核对已有配置支持的产品、气体或报告类型 | [SAM写入](./references/sam-create.md)                             | profiles 返回的目录足以回答支持范围时结束；不顺带研究新方案或查设备状态 |
| 只整理登记还缺什么信息                 | [Climber接口](./references/climber.md)                            | 对照字段复用用户已给信息，只列真正缺项；现场就绪查询留到用户需要时      |
| 新建、原地修改、报告勾选或另存为       | [SAM写入](./references/sam-create.md)                             | 新建按需 profiles/create；修改 inspect 后 modify/save-as，保留无关字段  |
| 运行单台 Climber                       | [Climber接口](./references/climber.md)，需要准备文件时再读SAM写入 | 复用方案和样品参数，查询当前状态，登记明确成功后再启动                  |
| 查询或运行预设自动化流程               | [流程接口](./references/automation.md)                            | 从 list/status 或已知流程标识进入；流程系统负责内部仪器调度             |

用户已指定方法、文件或操作时，直接进入对应入口；不要重新推荐方案或研究脚本源码。只缺分析口和原管号就问这两项，不要求重填已确认的名称、质量、方法、版本或路径。只有入口确实无法从上下文判断时才询问控制对象。

选择分支依据用户要取得的结果，而不是逐个展开句子中的专业词汇。支持范围、方法定义、登记缺项与当前就绪是不同问题；只在返回结果留下具体未答问题时扩展到另一分支。

## 复用输入，向前完成任务

- 使用当前环境提供的资料读取、知识检索与脚本调用能力；脚本路径和参数以所选契约为准。安装技能不代表设备连接，模拟响应不代表真实测量。
- 支持新建模板、修改模板和另存为。没有合适模板时用内置完整配置生成，不要求用户提供基准 SAM、完整 JSON 或内置配置已包含的软件版本；缺少样品名或称量时可先保存待填模板，依据 pendingInputs 说明缺项。
- 复用工具实际返回的 file.path；未指定位置时用脚本默认输出目录。仅在厂家访问路径或跨机映射确实缺失时询问对应条件，不把提供现成文件当作用户前置任务。
- 修改前核对文件哈希；报告选择用 modify 的顶层 reportTypes，仅切换 selected 并保留完整 options。另存为保留源文件，新建使用独立身份与实验前配置；不能用重建文件替代用户要求的原地修改。
- 批次/实验标识未指定时生成本次唯一标识，已有标识原样保留；物理分析口、原管号及实际称量按确认值使用。资料推荐、用户输入、文件事实和设备回执分别解释，不编造科学参数或仪器状态。
- 自动化流程与单仪器控制是独立入口。不要同时绕过流程直接启动其中的仪器。咨询或只读查询不授权写入；已明确授权且条件齐备的任务按依赖顺序完成，不逐步重复索取同一授权。

## 只追查具体缺口

返回结果足以回答问题时停止扩展。能力不匹配、参数错误、文件变化、服务失败或效果未知时，按 [诊断与恢复](./references/recovery.md) 处理实际错误，保留原任务和标识。不要用更换编号、参数或运行时重复未知写入，也不把服务查询失败当作仪器物理状态。

Wiki 提供推荐和历史配置证据；可执行文件配置由 SAM 接口处理。BET、BJH、DFT 不可互换；检索相似、文件写入成功、命令受理、实际运行、设备完成和报告可用是不同事实。未解决的方案标为 **模板推荐草案——参数尚未确认，不可下发运行**。

## 面向用户完成回复

使用中文简洁说明与当前问题有关的结论、实际执行结果和必要的下一步。测样以样品、测试目标、仪器和结果为主线；模板准备是内部步骤。用户询问或具体阻塞需要时再解释协议、文件和脚本细节，不在每次回复中展开完整参数表或通用前提清单。
