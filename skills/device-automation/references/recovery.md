# 按实际错误诊断并继续任务

只在遇到阻塞时阅读，保留用户本次目标、文件/批次/实验标识及最后确认结果。先区分请求没有执行、明确失败和效果未知，不因一次失败重新做全部准备。

| 实际观察                                               | 含义与下一步                                                                                                                          |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| 当前接口或脚本能力不存在                               | 核对当前宿主提供的能力与对应参考文档，只使用列出的操作。技能说明不自动注册工具或授予权限                                              |
| INVALID_COMMAND / INVALID_ARGUMENTS                    | 请求形状或命令名不正确。按脚本契约核对参数数组，SAM写入为独立命令字符串加一个JSON字符串；不猜新命令或阅读全部源码找替代入口           |
| profiles 没有匹配产品/气体配置                         | 现有完整配置不能满足该生成请求。说明实际缺少的配套配置；不从气体名称、Wiki摘要或另一产品拼造完整物性                                  |
| INVALID_INPUT / INVALID_SEGMENTS                       | 指明返回的具体字段问题，复用其余确认值；不擅自改变用户指定的管号、方法或限值                                                          |
| FILE_CHANGED                                           | 读取并核对当前文件与哈希，解释并发变化。不能在未确认当前内容时绕过哈希覆盖                                                            |
| INVALID_REPORT_OPTIONS                                 | 报告配置或勾选无效。仅切换勾选时 inspect 后用顶层 reportTypes；已有完整 options 留在文件内，不请求模型重新构造大数组                  |
| PRODUCT_STATUS_MISMATCH                                | 所选产品与文件家族冲突，部分字段暂不归一化；不等于原始共有编号无效。依据完整产品/版本与厂家合同决定后续，不仅改版本字符串就下发       |
| SERVICE_UNAVAILABLE / SERVICE_ERROR / INVALID_RESPONSE | 报告实际HTTP、通信或协议错误。没有取得的连接、就绪及忙闲字段仍未确认，不推断物理停机或损坏                                            |
| COMMAND_REJECTED                                       | 厂家明确拒绝；保留错误码和阶段。LOCAL_CONTROL_CONFLICT 按实际窗口占用处理；登记被拒绝后不启动，也不自动换批次编号重试                 |
| OUTCOME_UNKNOWN 或宿主报告执行unknown                  | 可能已产生外部效果。停止依赖写入，保留批次与阶段，使用宿主诊断及操作者对账流程；不能重复登记/启动，也不把退出、超时或取消当作设备停止 |
| 输出或资料超出限额                                     | 已返回的摘要足够时直接使用；确需更多信息时使用相应的有界读取/检查接口。不能把截断内容视为完整配置，也不重复读取同一大型文件           |

对于仅有参数或命令形状问题的请求，修正方案必须仍处于原授权范围；失败写操作不自动重放，设备效果不明时先对账。修复连接、配置或权限后回到原任务，不把故障排查扩展成新的测试或软件安装任务。

回复只说明与本次阻塞有关的事实、标识和下一步。保留产品版本、单位、来源哈希及证据缺口；历史配置、解析成功和模拟结果不能证明当前真实仪器动作。
