# 自动化设备接口契约

本契约定义设备发现与状态查询、任务下发和结果获取的操作及数据约定，不绑定特定 Agent 或工具名称。连接方式、权限、数据存储和运行配置由接口实现与部署环境提供；契约本身不证明设备已连接或操作已完成。

技能负责根据需求和可用资料匹配已有模板文件，接口接收文件名，由自动化设备在配置的目录中查找文件并执行任务。暂不支持生成、创建或修改模板，也不支持任务控制。接口不自行推断材料适用性或科学参数，不提供独立模板校验命令。

## 调用与配置

先确认宿主实际提供的设备接口调用方式。若使用[随附脚本](../scripts/instrument.js)，需要 Node.js 或兼容的 `.js` 运行环境；脚本路径相对于技能目录解析，以下数组表示命令及其参数，不是宿主工具名称。也可通过已配置并符合本契约的设备工具或服务执行对应操作，不假定存在特定脚本执行工具。

JSON 载荷作为单个参数传递，不拼成 shell 命令字符串。使用脚本时，检查退出状态及 JSON；错误结构为 `{ "error": { "code": "...", "message": "..." } }`，退出码非零。其他调用方式还应检查宿主提供的传输错误。

设备自行管理模板目录；Agent 不列举、读取或配置该目录。模板文件名从知识资料匹配结果或用户提供的信息取得，不猜测或拼造。存储位置、连接设置、超时和容量限制由接口部署配置决定，不在技能中指定用户主目录、宿主专用目录或配置变量。保留已下发文件名和接口返回的任务标识、报告位置，不直接修改模板或后端状态文件。连接或配置缺失时请求操作者补齐，不猜测路径或凭据。

## 操作

- 设备发现：`["list"]` → `{devices}`；状态查询：`["status", "<deviceId>"]` → `{device}`。
- 下发并运行：`["submit-measurement", "<提交 JSON>"]` → `{measurement}`；任务查询：`["measurement", "<measurementId>"]` → `{measurement}`。暂不提供暂停、恢复或取消等任务控制操作。
- 完成后获取结果：`["results", "<measurementId>"]` → `{result}`。
- 导出报告：`["export-report", "<measurementId>"]` → `{report}`，使用返回的报告位置，通过当前可用的文件或报告读取能力确认内容与任务一致。

设备标识必须来自发现结果，不硬编码或自行编造。选择前查询支持的方法和气体。仅选择满足需求的已有模板并保留准确文件名；没有合适模板时停止下发，请操作者准备文件，不创建或修改模板。

## 模板与下发数据

模板是设备目录中的已有文件，下发值为文件名，不是参数对象或新建模板的标识。`templateFile` 必须来自知识资料匹配结果或用户提供的信息，非空、最多 128 个字符、不包含控制字符、路径分隔符、Windows 文件名禁用字符或保留设备名，不以空白或点结尾；不提交绝对路径、相对路径或文件内容。不限定文件扩展名，格式和目录由设备管理。

设备接口不提供模板列举、读取、生成、保存或修改操作。Agent 根据已获得的资料和用户信息匹配适用条件；没有准确文件名或必要依据时停止下发，请用户或操作者补充，不根据材料名或方法名拼造文件名，也不要求读取模板内容或配置本地模板目录。

测量提交仅包含 `{ "deviceId": "...", "templateFile": "已有模板文件名" }`。设备收到文件名后自行查找文件，确认是否存在、适用及可运行；Agent 不声称已验证文件存在或内容。接口没有样品标识字段，不要求提供或自行生成样品编号；提交拒绝额外字段。每台设备同时只能有一个活动任务。任务保留下发文件名用于追溯；匹配依据由技能保留，不下发模板参数对象。该操作包含下发和启动，不需要额外启动命令；是否接受及实际运行状态以返回结果和后续任务查询为准。

## 任务状态与结果

任务状态通过接口查询确认，不根据经过的时间、脚本退出或预估时长推断完成。运行时间、进度和完成条件由设备接口实现确定。

当前流程支持查询 `running`（运行中）和 `completed`（已完成），不提供暂停、恢复或取消操作。用户要求任务控制时说明暂不支持，请操作者通过设备自身渠道处理。历史任务或其他接口返回已暂停、已取消、失败或未知状态时，保留原值并停止依赖成功状态的操作，不推断完成或设备已停止。

观察到完成后才能获取结果。保留返回的任务、设备、模板文件名、单位及来源信息，按设备文档解释数值，不补造未返回的数据或分析结论。报告位置和格式以接口返回为准，不假定固定本地目录，也不擅自指定输出路径或覆盖已有报告。无法读取报告时，说明已返回的位置和待确认事项，不宣称已验证导出成功。

## 授权与异常处理

只读查询不得触发写入。提交和报告创建必须在用户授权范围内，并遵守宿主审批、设备权限、运行前提、限值及联锁。模板文件由操作者管理，技能不得生成、保存或修改模板。凭据由部署环境管理，不放入技能资源。

区分调用失败、设备拒绝与效果未知。连接中断、超时或响应不明确时，保留已获得的操作标识，优先查询状态并请求操作者核对；未明确幂等规则前不自动重试写操作，不删除后端文件或重置状态。接口实现更换后，需确认字段、单位、状态、错误和完成证据仍符合本契约。
