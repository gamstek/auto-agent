# 自动化流程接口

## 控制对象

自动化设备执行预先设置好的一系列流程，具体步骤、顺序、仪器调用与联锁由自动化控制系统负责。AI 选择已有流程模板并提交运行，不自行生成流程、拆解执行步骤或在运行期间直接控制其中的单台仪器。

本契约不绑定特定 Agent 或工具名称。实际服务连接和权限由部署环境提供；契约存在不证明设备已连接。

## 调用入口

使用部署环境提供的自动化服务，或 `scripts/automation.js`。随附脚本是用于开发验证的模拟实现，不连接真实自动化设备，其设备、进度和结果不能作为真实运行证据。脚本使用 Node.js 22 或宿主支持的 JavaScript 运行时。以下为命令参数数组，不是 shell 字符串；JSON 作为单个参数传递。

| 操作           | 参数                           | 返回                                      |
| -------------- | ------------------------------ | ----------------------------------------- |
| 查询自动化设备 | `["list"]`                     | `{devices}`，包含设备标识、能力及忙闲状态 |
| 查询设备状态   | `["status", "<deviceId>"]`     | `{device}`，包含当前活动运行标识          |
| 提交流程并启动 | `["submit-run", "<JSON>"]`     | `{run}`，包含运行标识与实际状态           |
| 查询流程运行   | `["run", "<runId>"]`           | `{run}`                                   |
| 获取完成结果   | `["results", "<runId>"]`       | `{result}`                                |
| 请求流程报告   | `["export-report", "<runId>"]` | `{report}`，包含位置和格式                |

脚本退出非零时读取 `{error:{code,message}}`。模拟实现所有成功响应含 `backend=simulation`，结果和报告保留来源说明。真实服务必须提供可区分的数据来源；无法确认来源时不宣称真实测量完成。

## 提交数据

```json
{
  "deviceId": "从实际设备清单取得的标识",
  "templateFile": "资料或用户提供的已有流程模板文件名"
}
```

只接受 deviceId 和 templateFile。deviceId 必须来自设备清单，提交前重新查询状态；每台设备仅允许一个活动运行。此入口不接收单仪器的样品、管号、质量或 SAM 路径；必要的流程运行前提由已有模板及自动化控制系统管理，不在此附加未知字段。

templateFile 是准确文件名，不是路径、模板内容或参数对象：非空、最多 128 字符，不含控制字符、路径分隔符、Windows 禁用字符或保留设备名，不以空白或点结尾。文件扩展名由自动化系统决定。模板文件名必须来自知识资料或用户输入，不按材料/方法名称拼造。

模板目录与查找规则由接口部署配置决定，AI 不读取、列举或配置模板目录，不上传或改写文件。后端收到文件名后自行查找并判断可运行性；模拟实现仅记录文件名，不读取实际模板，也不证明模板存在或流程适用。

## 运行步骤

1. 查询 list 和目标 status，结合资料确认模板对应的整套流程、设备能力和运行前提。
2. 明确用户运行授权并补齐缺失信息，提交一次 submit-run；提交已包含启动，不额外启动单台仪器。
3. 保留 run.id、deviceId、templateFile 和匹配依据，使用 run 查询状态。running 表示流程运行中，completed 表示流程完成。未知、失败或其他状态保留原值，停止依赖成功的操作。
4. 确认整个流程完成后调用 results，用户需要报告时再调用 export-report。核对结果/报告所属 runId、设备及模板；报告无法读取时只报告返回位置，不声称内容已验证。

不提供模板管理、独立模板校验、流程编辑、暂停、继续或取消命令。用户要求这些操作时说明当前能力边界，交由自动化系统自身渠道处理。

## 异常

区分服务不可用、明确拒绝、效果未知、设备完成和结果尚未就绪。写入超时或响应不明确时保留运行标识（如已取得），先查询状态并请求操作者对账，不自动重试或改走单仪器入口。不能仅凭时间、退出码或某个仪器完成来认定整套流程完成。模拟实现的合成数值不能解释成样品的真实科学性质。
