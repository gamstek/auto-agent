# Climber 设备能力

Climber 单仪器控制通过已配置的 MCP Server 连接厂家软件 HTTP API，**不需要提交自动化流程**。根据实际工具目录选择对应设备实例；连接地址和宿主工具前缀由部署提供，不把示例工具名称拼接成未发现的调用。

## 能力与顺序

| 能力           | MCP 原始工具名称 | 参数                     | 厂家接口                             |
| -------------- | ---------------- | ------------------------ | ------------------------------------ |
| 查询健康       | `get_health`     | `{}`                     | `GET /api/v1/health`                 |
| 查询当前状态   | `get_status`     | `{}`                     | `GET /api/v1/status`                 |
| 登记批次       | `register_batch` | `{batchId, experiments}` | `POST /api/v1/tasks`                 |
| 启动已登记批次 | `start_batch`    | `{batchId}`              | `POST /api/v1/tasks/{batchId}/start` |

只查状态时直接查询，不要求用户准备模板，不必展开完整测样流程。MCP 连接、厂家接口可访问、仪器已连接、软件就绪和忙闲是不同事实。

测样流程：

1. 复用已知样品信息和方案；需要文件时按 [SAM写入](./sam-create.md) 准备模板。
2. 查询设备当前状态，确认实际设备和当前批次，没有其他流程/会话占用。
3. 登记批次，确认同一 batchId 的明确回执。
4. 再启动同一批次。登记不代表分析开始；STARTING 不等于 RUNNING。
5. 按用户目标有界查询，报告实际状态。只有已实现的持久化工作流服务才能承诺长期后台跟踪。

## 登记数据

```json
{
  "batchId": "BATCH-EXAMPLE-001",
  "experiments": [
    {
      "experimentId": "EXP-EXAMPLE-001",
      "analysisPort": 1,
      "tubeNo": 109,
      "samPath": "E:\\templates\\sample.SAM",
      "sampleName": "样品A",
      "emptyTubeMassG": 29.1,
      "sampleMassG": 1.5
    }
  ]
}
```

示例不是实际样品信息或授权。缺失项只询问真实缺失部分，不重问已确认参数。

- batchId 为1–64位字母、数字、点、下划线或连字符，不能为 `.` 或 `..`；已有批次/实验标识原样保留，未指定时生成本次唯一标识。
- 当前只支持左侧1–3项实验，analysisPort 为1/2/3；不推断右侧容量。
- experimentId 与分析口各自唯一。tubeNo 为原正整数，设备适配器映射到1..72，例如109→37、144→72；映射重号整批拒绝，保留原管号及映射。
- samPath 必须是厂家 Windows 主机可访问的**盘符开头、带具体文件名的绝对 `.SAM` 路径**。不能传模板目录或 UNC 路径。接口只传路径、不上传文件。
- 跨机生成时需使用明确的厂家路径映射；本机 file.path 不自动证明厂家可访问。优先复用已确认映射和工具实际返回的路径。
- sampleName 非空、最多128字符且不含非法文件名字符；emptyTubeMassG 为实际空管质量，sampleMassG 为实际净样质量，单位g，均为正有限数。
- 当前厂家接口只支持常规模式：SAM 写入 labType=0。历史 labType=1 是高通量模式，不是无效枚举；不能直接用于本接口。该字段在 SAM 内，不附加到登记请求中。
- 新建草稿的 pendingInputs 未补齐时，不当作可运行模板；接口不接受未经确认的占位质量。

## 回执与状态

设备工具返回结构化来源与状态。核对 batchId、原始 state 和实际提供的实验身份。厂家只提供当前单 task；新批次可能覆盖上一批，不能把当前投影当作完整历史查询。

查询失败时区分连接错误和最后已知事实。存在 stale 标记时说明更新时间；没有新鲜证据不能断言仪器物理离线、损坏或已停止。

COMPLETED 需要来自同批次的新鲜状态。设备完成不自动证明结果文件已保存；只有实际返回或另行核验的文件证据才能报告结果位置。

## 异常与对账

明确的厂家拒绝为 COMMAND_REJECTED。写请求超时、断连、回执缺少身份、批次不符、两处身份冲突或结果未能持久化时为 OUTCOME_UNKNOWN。

效果未知时保留 batchId、阶段和操作标识，停止依赖写入，只读核对；不重复登记/启动，不换批次编号绕过，不回退到直控脚本。登记未知不能启动，启动未知不能重新登记。软件退出、模型取消或 MCP 取消均不证明仪器停止。

如环境只提供外部自动化流程控制入口，按该入口提交整套流程，不同时调用内部仪器。没有发现对应设备能力时说明尚未配置，不研究或执行旧脚本作为替代连接。
