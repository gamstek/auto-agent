# LLM Wiki

Node 24 的纯文本知识编译库。接受 UTF-8 Markdown/TXT，由调用者注入模型连接；不包含聊天循环、设备字段、SQLite 或资料包接口。

摄入分为原文分析和知识页生成/合并。原始文本按内容哈希保留，Markdown 页面包含来源、日期和交叉引用。完整变更先写入新版本目录，最后原子切换 current 指针；失败/取消不替换上一发布版本。

```text
llm-wiki/
├─ raw/sources/<id>/<sha256>.txt
├─ purpose.md
├─ schema.md
└─ .state/
   ├─ current.json
   ├─ search-index.json       可重建缓存
   ├─ objects/               内容寻址的持久页面，版本间复用
   └─ generations/<uuid>/
      ├─ manifest.json
      └─ wiki/
         ├─ index.md
         ├─ overview.md
         ├─ log.md
         ├─ sources/
         ├─ entities/
         ├─ concepts/
         └─ topics/
```

目录查询返回实际 wikiDirectory，可打开阅读 Markdown。版本目录中的知识页是持久产物，不是可丢弃缓存；旧引用绑定 generation/path/sha256，不能自动跳到最新版。用户修改 purpose/schema 指导后续摄入；已发布页被外部改动时会报校验错误，不覆盖未知改动。

未变化页面复用内容寻址对象；文件系统支持时以硬链接组成完整版本目录，避免每次完整复制知识正文。不支持硬链接时仍以完整文本文件发布，接口和引用语义相同。

缓存复用要求来源哈希、管线/模型/规则指纹一致，且生成页面完整并继续引用原文版本。已有其他来源的引用不能在页面合并中丢弃。未确认问题保留在后续概览和日志中，不假定已解决。

明确的用户结论可用 resolve 关闭对应记录，原因追加到日志；知识正文不会自动重写，关闭记录不代表科学验收。

搜索默认只查生成的知识页，用关键词和中文词元；需要时按引用回读固定原文。reindex 仅生成 JSON 检索缓存，不调用模型。lint 只检查页面、链接和来源完整性，历史引用单独报告，不冒充语义或科学验收。

长文按分段分析，单次最多 24 段；实际上下文还受到宿主模型容量限制。内容过长、模型输出截断、路径/来源无效或并发基线变化均停止发布，不静默截断后当成完整知识。一次批量摄入按来源逐项发布，取消不会回滚之前已经完成的来源。
