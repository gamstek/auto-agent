# 知识库

## 查询

按问题查目录或搜索知识页，阅读相关页面；需要核对事实、条件或冲突时回读其固定原文。使用宿主提供的通用 Wiki 能力及 knowledge 集合，参数和分页遵循当前工具契约。

知识页是 LLM 综合内容，原文是证据。回答说明两者的区别，保留来源、版本、数值、单位和未决问题。查询不会自动生成或改写知识页。

## 摄入与维护

先区分“添加资料来源”和“开始整理”：添加只登记配置，整理才调用模型并生成持久知识。用户明确要求整理、摄入或更新后，复用已配置来源，按其指定范围执行 ingest；范围不清时先确认。

根据实际结果报告已处理资料、生成页面、失败和待确认项；取消后的已发布内容仍保留，不自动重放失败来源。移除来源配置与删除已生成知识是不同操作，不把前者说成已经忘记资料。

用户明确给出待确认项的处理结论后，才使用 resolve 记录说明。说明它关闭的是问题记录，正文需要另行整理；结构检查或关闭记录不代表科学验收。仪器内置资料、工具输出和聊天历史不自动转为用户知识来源。
