# 材料预处理与测试模板选择规则

本文根据材料类型和测试需求选择建议设备、样品预处理条件与测试模板。模板的压力段、注气、平衡和报告设置见 [模板定义](模板定义.md)。

## 选择流程

1. 查找材料对应的测试需求、气体、温度与预处理条件。
2. 按下表选择 BET、微孔或介孔模板类别；不要仅因为需求中出现“比表面积”或“BET”就选 BET 模板。
3. 在该类别内应用细分规则，输出明确的模板名称与尚待确认的信息。

| 测试需求                                        | 模板类别     | 细分依据                                      |
| ----------------------------------------------- | ------------ | --------------------------------------------- |
| 仅需测比表面积，或含 BET 且不含全孔、孔径、微孔 | BET测试模板  | 预估 BET 比表面积、是否首次六点法无法选出 BET |
| 比表面积+全孔分析                               | 微孔测试模板 | 完整客户需求文本，以及气体和温度              |
| 比表面积+介孔分析                               | 介孔测试模板 | 非多孔碳或多孔碳材料分类                      |

设备列记录建议设备，不参与 BET 大比表判定，也不能替代测试需求匹配。未匹配的需求应保留原文，标为“未匹配”并转人工确认。

## BET 测试模板细分规则

适用前提：仅需测比表面积，或需求含 BET 且不含全孔、孔径、微孔。

| 条件                                 | 选择模板                 | 备注                   |
| ------------------------------------ | ------------------------ | ---------------------- |
| 首次六点法无法选出 BET               | BET测试模板-六点加密重测 | 重测场景               |
| 预估 BET 比表面积 ≥1000 m²/g         | BET测试模板-大比表       | 大比表判定为“是”       |
| 预估 BET 比表面积 <1000 m²/g         | BET测试模板-默认模板     | 大比表判定为“否”       |
| 无预估值，或大比表判定为空白、待确认 | BET测试模板-默认模板     | 必须备注“大比表待确认” |

“六点加密重测”是模板名称；具体压力段按 [模板定义](模板定义.md)，不由名称推导点数。

## 微孔测试模板细分规则

适用前提：测试需求为“比表面积+全孔分析”。材料表中的该需求仅确定微孔模板类别，不自动确定某个子模板。

- 必须按下表中的**完整客户需求文本**匹配，不按“BET”“10^-7”“吸附”等局部关键词猜测。
- 匹配优先级：先匹配“分压比达到10^-7且关注超微孔占比（77K，氮气）”，再匹配“分压比达到10^-7（77K，氮气）”；其余按完整文本匹配。
- “默认模板（77K，氮气）”只在客户需求就是该项时使用；有更具体需求时按具体需求匹配。
- 没有完整匹配时输出“未匹配”，附客户需求原文，转人工确认；不得回退到默认模板。
- 匹配出的模板还需与已提供的气体和温度核对；冲突应列为待确认，不覆盖用户条件。

| 完整客户需求文本                             | 对应模板名称                       |
| -------------------------------------------- | ---------------------------------- |
| 默认模板（77K，氮气）                        | 微孔常规测试模板                   |
| 分压比达到10^-7（77K，氮气）                 | 微孔常规测试模板-低压10^-7         |
| 分压比达到10^-7且关注超微孔占比（77K，氮气） | 微孔常规测试模板-超微孔            |
| 实验结果与麦克对标（77K，氮气）              | 微孔常规测试模板-麦克对标          |
| 低压段点数设计密集（77K，氮气）              | 微孔常规测试模板-低压等温线        |
| 仅进行吸附（77K，氮气）                      | 微孔常规测试模板-仅进行吸附        |
| CO2分析超微孔占比（273K，CO2）               | 微孔常规测试模板-CO2分析超微孔占比 |

## 介孔测试模板细分规则

适用前提：测试需求为“比表面积+介孔分析”。

| 材料分类   | 原表模板选项 | 对应模板名称       |
| ---------- | ------------ | ------------------ |
| 非多孔碳   | 默认模板     | 非多孔碳介孔模板   |
| 多孔碳材料 | 多孔碳       | 多孔碳介孔测试模板 |

原表在多种无机材料、金属、树脂等条目中重复了这两条规则，但未给出这些材料如何归入“非多孔碳/多孔碳”的完整映射。材料表只保留其“介孔”类别；细分分类不明确时标为待确认，不自行扩展“非多孔碳”的含义。

## 样品预处理条件的解释

- 温度区间（如 200–300 ℃）表示在区间内选一个固定温度恒温，不表示从下限程序升温到上限。
- 时间区间（如 2–4 h）表示选一个固定时长，不表示逐步延长。
- “≤60 ℃”“≤40 ℃”表示固定设定温度的上限，不是升温程序。
- “90 ℃、1 h 后升至 300 ℃、6 h”是原表明确给出的分阶段条件，保留该顺序；升温速率未给出。
- 这些是**样品预处理条件**，不能直接当作仪器测试前的准备抽真空参数。
